## Featured Projects

### 1. StockSense AI Inventory

**An AI-assisted inventory management system for small businesses.**

StockSense is designed around a practical problem faced by small shops: managing inventory through paper registers, scattered messages, and manual stock calculations.

The project explores how a digital inventory system can help staff track stock movements, identify low-stock products, and retrieve inventory information more conveniently.

Key features and goals include:

- Product and inventory management.
- Recording stock-in and stock-out movements.
- Low-stock monitoring and inventory history.
- An AI assistant for inventory-related questions.
- Human confirmation before AI-proposed stock changes are applied.
- Separate permissions for managers and staff.
- Backend-driven inventory operations and database integration.
- Protection against invalid stock updates and negative inventory.

**Technologies:** React, Vite, Python, FastAPI, Supabase, AI integration.

The project has helped me explore how frontend interfaces, backend APIs, database operations, access control, and AI-assisted workflows fit together in a practical business application.

### 2. AdmitCrew / AdmitQ

**An AI-assisted admissions support system for study-abroad consultants.**

AdmitCrew explores how an AI-powered team can support an admissions consultancy where staff receive repeated questions about university programs, application requirements, fees, deadlines, IELTS, and documents through multiple communication channels.

The system is designed to help organize student inquiries and support staff without removing human oversight from important decisions.

Key features and goals include:

- AI-assisted responses to common student questions.
- Student inquiry and lead management.
- Document-checking workflows.
- Follow-up assistance for prospective students.
- Organized admissions information.
- Escalation of situations that require staff attention.
- Human oversight for important admissions decisions.

**Technologies:** React, Vite, AI Studio, API and workflow integration.

This project has encouraged me to think about AI as more than a chatbot. It demonstrates my interest in designing coordinated workflows where different automated tasks support a larger business process.

### 3. AI Vet Agent

**An AI-assisted animal health information and triage support project.**

AI Vet Agent explores how an intelligent application can help pet owners organize information about an animal's symptoms and provide preliminary guidance about possible urgency.

The project focuses on collecting relevant information, supporting image and symptom inputs, and presenting understandable next steps without claiming to replace a veterinarian.

Key features and goals include:

- Animal profiles and relevant pet information.
- Symptom-based information processing.
- Support for animal image analysis.
- Preliminary urgency and triage guidance.
- Structured responses and suggested next steps.
- Backend API functionality.
- Exploration of multilingual and retrieval-based assistance.

**Technologies:** Python, FastAPI, SQLite, AI integration.

This project allows me to explore how AI applications can handle user-provided information while communicating limitations clearly, especially in areas where professional judgment matters.
